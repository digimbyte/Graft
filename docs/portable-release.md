Portable Graft 0.1.0 packages Graft 0.17.0 and Node 24.11.1 for Windows x64,
Linux x64 (glibc 2.35+), and macOS 15+ on Apple Silicon.

- Codex marketplace entries with prebuilt runtimes; no local npm or compiler setup.
- Local first-use indexing, caller tracing, code search, and automatic graph refresh.
- Versioned downloads with SHA-256 integrity checks and per-user caching.
- Telemetry disabled; MCP startup leaves host configuration and agent instructions unchanged.

Install and management instructions: [docs/portable.md](https://github.com/digimbyte/Graft/blob/main/docs/portable.md).

Artifacts include Node, production dependencies, and their license notices.
